# Lumi 

Windows x64 本地屏幕调节工具。

- 多屏亮度控制，可选联动与预设。
- 按设备能力提供硬件对比度和 HDR 控制。
- 精简托盘快捷面板，支持悬停和点击呼出。
- 三款内置托盘图标与自动系统主题配色。
- 统一对齐与留白，支持原生毛玻璃和系统圆角。

下载 `lumi.zip`，解压后运行 `lumi.exe`。

推荐 Windows 11 x64，.NET Framework 4.8。EXE 未签名。DDC/CI、HDR 和毛玻璃效果依赖硬件与系统支持；不保证所有设备兼容
